# React Native Ecommerce App

A full-featured ecommerce mobile application built using React Native and Redux Toolkit.  
This project demonstrates a complete end-to-end shopping experience integrated with a custom REST API backend.

## 🚀 Features

- User Authentication (Login & Register)
- Product Listing with Category Filtering
- Product Detail Screen
- Add to Cart & Cart Management
- Checkout Flow
- Order History
- Global State Management with Redux Toolkit
- REST API Integration with Axios

## 🛠 Tech Stack

### Mobile

- React Native
- React Navigation
- Redux Toolkit
- Axios

### Backend

- Node.js
- Express.js
- PostgreSQL
- Railway (Cloud Deployment)
- Swagger (API Documentation)

This project showcases my ability to build scalable fullstack applications across mobile and backend systems, focusing on clean architecture, state management, and real-world ecommerce functionality.
